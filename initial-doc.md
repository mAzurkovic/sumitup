## Current State

When browsing the web, some websites have lots of information to be read in order to be correctly understood. This gives rise to the problems:

1. **Time:** Takes a long time to read such information
2. **Understanding:** Often these pages, documents, artiles, etc. have lots of concepts. The larger the page, the more difficult it is to understand the topics being discussed. 

## Solution: “Sum it up”

**Sum it up** is a browser extension (Chrome for now) that allows users to summarize a web page, or portions of a web page.

**Use case 1: Whole Web Page Summary**

When navigating to a webpage with text or video content (e.g. a Wikipedia article or a YouTube video), I can press the browser extension “Sum it up” icon and it opens up a side panel in browser (on right side same page) with the summary of the page.

**Use case 2: Highlighted Text Summary**

When on a page, I can highlight a portion of text. This brings up a pop-up above the text with the summarized information. A link at bottom says “More” to open the side pane.

**Use case 3: Select Detail-Level of the Summary**

In the side panel, I can select different “detail levels” of the summary: “short”, “medium”, “in-depth”. These dictate how detailed the summary generated is.

**Use case 4: Chat bot**

In the side pane, at the bottom, a chat bot is present for the user to follow up with more questions/clarifications to understand the content more.
